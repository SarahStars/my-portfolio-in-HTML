# موقعي الشخصي (My Portfolio)

موقع شخصي أعرض فيه نبذة عني ومشاريعي ومهاراتي، بنيته أثناء تعلّمي تطوير الويب.

🔗 **الموقع المباشر:** https://sarahstars.github.io/my-portfolio-in-HTML/

## المميزات

- وضع ليلي ونهاري مع حفظ اختيار الزائر في المتصفح
- عرض المشاريع والمهارات من بيانات (JavaScript) بدل كتابتها يدوياً
- نموذج تواصل مع التحقق من الحقول قبل الإرسال
- كود مقسّم إلى ملفات (ES Modules)

## التقنيات المستخدمة

- HTML
- CSS
- JavaScript

## هيكل المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم والألوان |
| `data.js` | بيانات المشاريع والمهارات |
| `render.js` | عرض المشاريع والمهارات في الصفحة |
| `theme.js` | الوضع الليلي |
| `form.js` | التحقق من نموذج التواصل |
| `main.js` | نقطة تشغيل الموقع |

## ما تعلمته من المشروع

- التعامل مع (DOM) والأحداث (events)
- استخدام `map` لعرض القوائم من بيانات
- تقسيم الكود باستخدام `import` و`export`
- نشر موقع على (GitHub Pages)
